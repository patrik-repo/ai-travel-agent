# Comparative Destination Analysis — Pro/Contra Format

## Template: Per-Destination Analysis Table

```markdown
### 🇹🇷 Antalya
| ✈️ Flug | 🏨 4★/N | 🍕 Pizza | 🎯 Teen | 💰 Pauschal* | 💰 Total |
|---------|---------|----------|---------|-------------|----------|
| €253 (3h15, direkt, SunExpress) | €90 | €3-4 | **9/10** | ~€1.000 | **~€1.350** |

- ✅ **Beste Action** — Aquaparks, Bazaar, Beach-Clubs, Wassersport
- ✅ **Teen-Paradies** — 15-jährige Tochter liebt's
- ✅ Direktflug, kurze Transferzeit (30 Min)
- ❌ Im Juli/August **35-40°C** — sehr heiss
- ❌ Touristisch, kein Geheimtipp-Gefühl
```

## Template: Ranked Summary Table

```markdown
### 🎯 Meine Empfehlungen — Top 3

| Rang | Ziel | Flug+Hotel | Warum |
|------|------|-----------|-------|
| 🥇 | **Antalya** | **€1.136** | Direktflug, Teen 9/10, Action, günstigstes Direktziel |

```

## Rules

1. ALWAYS show 5+ destinations, never fewer
2. ALWAYS include both pros (✅) and cons (❌) per destination
3. ALWAYS include a ranked summary at the end
4. NEVER lock onto a single destination before the user picks
5. Live prices from Google Flights take priority over knowledge base estimates
6. Hotel estimates from knowledge base unless live data available
7. Per-destination analysis includes: flight details, hotel price, food cost, teen/family rating, 3+ pros, 3+ cons
