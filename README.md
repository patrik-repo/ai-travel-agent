# 🌍 AI Travel Agent - for Hermes Agent

**92 destinations. 12 questions. 1 HTML page.**

Tell your Hermes Agent "I want a week of beach vacation in July with my daughter" — the rest happens automatically.

## ✨ What This Skill Does

- 👑 **12-Question Workflow** — language, departure, dates, budget, hotel preferences... the agent asks EVERYTHING
- ✈️ **Live Prices** from Google Flights, Hotels, Skyscanner & Kayak — real CHF/EUR values
- 🏨 **10+ Hotels** with location, pool, breakfast, ratings — 3 budget variants (Budget/Mid/Comfort)
- 🌍 **Comparison Table** with up to 10 destinations — pro/contra for each
- 🎨 **Beautiful HTML Page** with PDF button — no account, no app needed
- ⚠️ **Honest & Transparent** — prices are non-binding, sources always cited

## 🚀 Quick Start

```
User: "I want a week somewhere warm in July with my daughter (15)"
Agent: [12 questions] → [Live research] → [HTML page with comparison]
```

## 📦 Installation

```bash
hermes skills tap add patrik-repo/ai-travel-agent
hermes skills install travel-agent
```

## 📋 Requirements

- Hermes Agent (Linux/macOS)
- Nothing else. No API key. No account.

## ⚠️ Disclaimer

All prices are non-binding best-effort approximations based on information available at query time. Always verify prices with the provider before booking.

## 🛠️ Built With

- 92 researched destinations (prices, vibe, teen rating)
- Live price queries via Google Flights & Hotels
- HTML template with CSS orange theme
